# 🧩 React + Express CRUD App ( Database)

A simple full-stack **CRUD (Create, Read, Update, Delete)** project built using:
- **Frontend:** React.js  
- **Backend:** Express.js  
- **Storage:** In-memory (No database)

This project demonstrates how the **frontend** communicates with the **backend API** using `Axios`, performing all CRUD operations.

---

## 🚀 Features

✅ Add new users  
✅ Edit existing users  
✅ Delete users  
✅ Fetch and display all users  
✅ Real-time updates between frontend and backend
