# 🧩 React + Express + MySQL CRUD Application

A simple full-stack **CRUD (Create, Read, Update, Delete)** web application built using  
**React (Frontend)**, **Express.js (Backend)**, and **MySQL (Database)**.  

This project demonstrates how frontend and backend communicate via REST APIs,  
and how data is stored and managed in a MySQL database.

---

## 🚀 Features

- Add new user details (Name & Age)
- View all users from MySQL
- Edit and update existing user information
- Delete user records
- Connected to a live MySQL database using Express.js
- Responsive and clean UI with minimal CSS

---

## 🛠️ Tech Stack

**Frontend:** React.js, Axios  
**Backend:** Node.js, Express.js  
**Database:** MySQL  
**Styling:** Pure CSS
